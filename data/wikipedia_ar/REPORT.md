# ويكيبيديا العربية: فحص ملفات العناوين (بدون نص، بدون تدريب)

`python -m data.wikipedia_titles_audit` → `data/wikipedia_ar/audit.json` (كل الأرقام أدناه مع أمثلة).
الملفان من commit `71dfac1` (Git LFS)، وتطابقا مع sha256 الخاص بالـ LFS، ولا يُرفعان إلى git من هذا الفرع.
لم يتغير شيء في الـ dataset أو الـ tokenizer أو الموديل الرسمي.

## 1. ما هو كل ملف

| | `all-titles-in-ns0.gz` (14.4 MB) | `multistream-index.txt.bz2` (33.9 MB) |
|---|---|---|
| الصيغة | عنوان في كل سطر، `_` بدل المسافة، أول سطر `page_title` | `offset:page_id:title` (العنوان مُرمَّز HTML: `&quot;`، `&amp;`) |
| النطاقات | النطاق 0 فقط (مقالات + تحويلات) | كل نطاقات `pages-articles-multistream.xml.bz2` |
| العدد | **2,451,316** عنوانًا (0 تكرار حرفي) | **3,918,700** سطر (0 سطر معطوب) |
| article id | لا | **نعم**: 3,918,700 رقم صفحة فريد، بدون تكرار |
| byte offset | لا | **نعم**: **39,193** offset فريد = كتل bz2 في كل منها 100 صفحة (الأخيرة 8)؛ آخر offset هو 2,156,989,553، أي أن ملف XML الكامل ≥ 2.16 GB مضغوطًا |
| العنوان | نعم | نعم |
| علامة التحويل (redirect) | **لا** | **لا** |
| نص المقالات | **لا** | **لا** |

النطاقات في الـ index: مقالات (النطاق 0) 2,451,281 · تصنيف 1,117,210 · قالب 144,237 · ملف 58,310 ·
ويكيبيديا 54,651 · بوابة 49,454 · موضوع (نقاشات) 34,649 · وحدة 6,590 · ميدياويكي 1,374 · مساعدة 741 · فعالية 203.

**العلاقة بين الملفين:** جزء النطاق 0 في الـ index هو نفس قائمة `all-titles`. بعد فك ترميز HTML:
2,451,279 عنوانًا مشتركًا، 37 في all-titles فقط، و 2 في الـ index فقط (صفحات أُنشئت أو نُقلت بين وقتي التصدير).
أي أن all-titles لا يضيف شيئًا غير موجود في الـ index؛ والـ index يضيف أرقام الصفحات والـ offsets وباقي النطاقات.

**عدد المقالات الفريد: لا يمكن معرفته من هذين الملفين.** الـ 2.45M عنوانًا في النطاق 0 تشمل التحويلات، ولا يميزها
أي من الملفين. مؤشرات التحويلات: 501,566 عنوانًا لاتينيًا فقط (20.5%، مثل `Michael Braithwaite`، `NGC 3185`:
أسماء أجنبية تحوّل إلى مقالات عربية)، و 95,565 مجموعة عناوين تختلف فقط في الهمزة / التاء المربوطة / الألف المقصورة /
المسافات (216,637 عنوانًا، مثل 21 كتابة لـ «مجلة الشريعة والدراسات الإسلامية»). إحصاءات ويكيبيديا نفسها (من خارج
هذه الملفات) تقدّر المقالات العربية بنحو 1.2M، أي أن قرابة النصف تحويلات على الأرجح.

## 2. العناوين (النطاق 0: 2,451,316)

| الكتابة | العناوين | النسبة |
|---|---|---|
| عربي | 1,925,072 | 78.5% |
| لاتيني فقط | 501,566 | 20.5% |
| كتابات أخرى (صينية، كورية، ثانا، …) | 11,045 | 0.45% |
| أرقام / رموز فقط | 8,102 | 0.33% |
| عربي + لاتيني | 5,531 | 0.23% |

أمثلة (عشوائية):
- مقالات عادية: ولاية فالكون · لوحة مفاتيح الإبهام · فوسفوإينول بيروفات كربوكسيلاز · العلاقات بين لبنان وباكستان · كريمان شفيق
- تحويلات محتملة: `Michael Braithwaite`، `National Library of Algeria`؛ أبو يعلى الزواوي / ابو يعلي الزواوى (13 كتابة)
- صفحات توضيح: 33,311 عنوانًا تنتهي بـ «(توضيح)»، مثل `0 (توضيح)`، `قائمة (توضيح)` (صفحات التوضيح بدون هذه اللاحقة لا تُعرف بدون النص)
- أرقام / رموز / لاتيني: `1957`، `٢٠٢٩`، `!`، `📗`، `(120181) 2003 UR292`، `/dev/null`
- مختلط: ايرباص A310 · مستقبلات 5-HT2A · لغة البرمجة R

**الطول:** متوسط 16.6 حرفًا، الوسيط 15 (p90 = 28، الأقصى 150)؛ متوسط 2.7 كلمة، الوسيط 2
(كلمة واحدة: 226K، كلمتان: 1.13M، 3: 651K، 4: 243K، 5 فأكثر: 204K).

**أكثر الكلمات في العناوين:** العلاقات / علاقات (110K: «العلاقات بين X وY»)، في، توضيح، بين، بن، لاعب، كرة، مقاطعة، عبد،
محمد، قدم، فيلم، قائمة، كأس، المتحدة، الدوري. أكثر التوصيفات بين قوسين: توضيح 33K، فيلم 12K، فلم 10K،
لاعب كرة قدم 7.7K، سياسي 5.8K، footballer 5.8K، مسلسل 5.4K. القائمة تهيمن عليها الأسماء: أشخاص، أماكن، رياضة،
أفلام، وصفحات «العلاقات بين دولتين» المولّدة آليًا.

**غير مناسب كنص تدريب** (الأعداد متداخلة): لاتيني فقط 501,566 · تحويلات بفروق إملائية ~121K زائدة ·
توضيح 33,311 · سنوات / تواريخ فقط 23,509 · قوائم («قائمة …») 14,012 · رموز / أرقام فقط 8,102 ·
`/` في العنوان 1,696 · محارف غير مرئية أو اتجاهية 1,460 · أطول من 100 حرف 35 (مثل عبارات المخاطر «R48/20/21/22: …»).

## 3. العناوين والـ BPE القديم 4K (100K عنوان عربي عشوائي)

- 1.91 حرف لكل token (نثر v2: 2.4–2.5): العناوين أسماء ونقحرات يقطعها الـ BPE إلى قطع صغيرة.
- byte fallback 0.08% من الحروف (أرقام فارسية ۰-۹، أرقام مشرقية، ZWNJ).
- 56.4% فقط من كلمات العناوين موجودة في نص التدريب العربي لـ v2؛ 54,332 من 66,659 كلمة مختلفة جديدة عليه.

## 4. التوصية

**ما نستطيع فعله بهذه الملفات الآن**
- معرفة حجم وشكل ويكيبيديا العربية: ~2.45M عنوان في النطاق 0، 3.92M صفحة، 39,193 كتلة مضغوطة.
- التخطيط لاستخراج انتقائي: بالـ index يمكن قراءة مقالة واحدة من ملف XML بفك ضغط كتلتها (100 صفحة) فقط،
  بدون فك 2+ GB.
- استخدام العناوين العربية كـ **معجم أسماء لأغراض التقييم**: مقياس «الكلمات المخترعة» يحسب حاليًا الأسماء الحقيقية
  (أماكن، أشخاص) ككلمات مخترعة؛ إضافة كلمات العناوين إلى معجمه تجعله أعدل.
- قياس تغطية الـ tokenizer للأسماء (أعلاه).

**ما يحتاج ملف XML الكامل** (`pages-articles-multistream.xml.bz2`، ≥ 2.16 GB؛ dumps.wikimedia.org محجوب في هذه البيئة)
- أي نص مقالات، وبالتالي أي corpus لغوي
- معرفة التحويلات، العدد الحقيقي للمقالات، صفحات التوضيح بدون «(توضيح)»
- طول المقالات وجودتها وتصنيفاتها؛ وdedup نصها مع v2

**العناوين كبيانات مساعدة؟**
- **للـ LM: لا.** 1.9M اسم من كلمتين (~31M حرف، 7 أضعاف v2 كلها) بلا جمل؛ حتى بوزن صغير ستعلّم الموديل كتابة
  قوائم أسماء، وهو عكس ما أظهرته المرحلتان 6 و 7 أنه مطلوب.
- **للـ tokenizer: ممكن، لاحقًا**، كتجربة مضبوطة منفصلة (وزن صغير للعناوين العربية في تدريب BPE لتعلّم قطع الأسماء)،
  تُقارَن بالـ BPC كما في المرحلة 4. ليس الآن: الـ tokenizer مثبّت.

**النصيحة:** احتفظ بالعناوين للتحليل والتقييم فقط، ولا تدخلها في التدريب. إذا أردت نص ويكيبيديا العربية، فالخطوة
التالية هي الحصول على ملف XML (خارج هذه البيئة)، ثم استخراج النص الصافي لمقالات النطاق 0 غير التحويلية، وتنظيفه،
وإزالة التكرار، مع حفظ نَسب CC BY-SA 4.0، ثم فحصه كما فُحصت الكتب قبل أي تدريب.
